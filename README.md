# English Learning Studio

A bilingual Bengali–English learning app for a Bengali-speaking beginner:
vocabulary, pronunciation, reading, listening, speaking, sentence
construction and practical communication.

## What's inside

- **125 lessons** (Basic English, Lesson 1 "Meeting New People" through
  Lesson 125 "Things I Need and Do Not Need"), each with vocabulary with
  Bengali meanings, phrases/sentences, synonyms and antonyms with Bengali
  meanings, examples, micro-stories, a full bilingual lesson story,
  flashcards, games, quizzes, saved vocabulary, progress tracking,
  spaced-repetition review and analytics.
- **Oxford 3000** — 3,003 words in 302 book-style stories (31 modules),
  Everyday Life first, then A1, A2, B1, B2, with a Vocabulary List
  (Word | Pronunciation | Meaning), examples, and synonym/antonym stories.
- **Phrasal Verbs** — 3,524 entries in 726 stories across 88 modules:
  Most common (77), More common (208), Business English (100) and the
  Complete A–Z list (3,139).
- **Idioms and Phrases** — 310 idioms in 63 connected real-life stories,
  each with a Practice Worksheet (MCQ, fill in the blanks, sentence making).
- **Exams** — 25 checkpoint exams (one after every 5 lessons) plus a final
  IELTS-style speaking practice exam.
- Focus timer, daily goal, dictionary, My Words, Review queue, Stats and
  Settings (Light / Dark / System theme, speech speed, language).

## Tech

React + TypeScript (strict) + Tailwind CSS, with a Bun server layer and
Drizzle/SQLite for saved progress. Built with Bun 1.3.10.

```sh
bun install
bun run typecheck
bun run build
```

## Google sign-in

Google sign-in is wired but not configured: put a real Google OAuth Client
ID in `client/src/google-config.ts` (`GOOGLE_CLIENT_ID`). Until then the
welcome screen offers a "Testing Project" entry that opens the app directly
with no account.

## Notes

- The mascot image `client/src/assets/pup-mascot.webp` is not in this
  repository (binary asset); the app falls back gracefully without it.
  Re-add it at that path to restore the mascot.
- `app.db` (learner progress data) is intentionally not committed.
  Built output (`client/dist`, `server/dist`) is regenerated by `bun run build`.
